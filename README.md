# SmartPark: Sistem Kalkulator Tarif & Slot Parkir

## Deskripsi Singkat
SmartPark adalah aplikasi berbasis konsol menggunakan bahasa pemrograman Pascal yang dirancang untuk memudahkan pengelolaan transaksi parkir kendaraan secara otomatis, menghitung durasi serta tarif total berdasarkan jenis kendaraan, dan memantau ketersediaan slot parkir secara real-time.

## Fitur Utama & Logika Program
1. **Menu Interaktif (`repeat-until`)**: Navigasi utama program yang terus berjalan sampai pengguna memilih opsi keluar.
2. **Kalkulator Tarif Parkir (`case-of` & `if-else`)**: Menghitung biaya berdasarkan selisih jam masuk dan keluar dengan tarif berbeda untuk Motor dan Mobil, serta memberikan diskon otomatis jika durasi melebihi 5 jam.
3. **Validasi Input (`while-do` & `continue`)**: Memastikan masukan jenis kendaraan atau data benar dan mencegah error.
4. **Cek Slot Parkir (`for-to-do`)**: Menampilkan daftar ketersediaan slot parkir secara berulang.
